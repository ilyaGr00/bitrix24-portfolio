# Подход к работе

При разработке я стараюсь использовать штатные возможности Bitrix24 и официальные API.

Перед внесением изменений:

- анализирую существующее решение;
- изучаю внутренние классы платформы;
- проверяю гипотезы через PHP-консоль;
- тестирую изменения на отдельном портале;
- добавляю журналирование;
- проверяю возможные побочные эффекты;
- только после проверки переношу решение в рабочую систему.

Такой подход позволяет снизить риск ошибок и упростить дальнейшее сопровождение проекта.
