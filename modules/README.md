# Локальные модули

Здесь размещаются законченные доработки для коробочной версии Bitrix24.

Каждый модуль должен содержать:

- описание задачи;
- структуру файлов;
- инструкцию по установке;
- инструкцию по удалению;
- список используемых событий и API;
- ограничения;
- обезличенный исходный код.

## Планируемые проекты

- синхронизация сделки и смарт-процесса;
- вспомогательные обработчики CRM;
- диагностические модули.
