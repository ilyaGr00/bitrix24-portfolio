# Синхронизация сделки и смарт-процесса

## Задача

Запускать бизнес-процесс сделки после изменения связанного элемента смарт-процесса.

## Проблема

Стандартные механизмы запуска бизнес-процесса сделки не всегда реагируют на удаление или изменение связанных элементов смарт-процесса.

## Решение

Локальный модуль регистрирует обработчики событий, определяет связанную сделку и обновляет её техническое поле. Изменение поля используется как штатный повод для запуска бизнес-процесса.

## Используемые механизмы

- D7 API;
- EventManager;
- CRM Service Container;
- Factory;
- Dynamic Item;
- журналирование.

## Структура

```text
src/local.dealproductsync/
├── include.php
├── install/
│   ├── index.php
│   └── version.php
└── lib/
    └── SmartProductHandler.php
```

Исходный код будет добавлен после повторной проверки и полного обезличивания.
