# PHP-действия для бизнес-процессов

Здесь будут находиться небольшие законченные блоки PHP-кода, которые запускаются внутри действия бизнес-процесса.

## Планируемые категории

- получение документа и его полей;
- работа с переменными бизнес-процесса;
- CRM;
- компании;
- сделки;
- смарт-процессы;
- пользователи;
- коллабы;
- почта;
- файлы;
- журналирование;
- обработка ошибок.

Каждый пример должен содержать описание входных данных, результата и ограничений.
