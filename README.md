Портфолио

Меня зовут Илья. Я занимаюсь доработкой и диагностикой коробочной версии Bitrix24.

Разрабатываю бизнес-процессы, PHP-блоки и локальные модули. Работаю с CRM, смарт-процессами, коллабами, почтовыми событиями и агентами.

В работе стараюсь использовать штатные API Bitrix. Новые решения сначала проверяю на тестовом портале, после чего переношу в рабочую систему.

## Основные направления

- разработка бизнес-процессов Bitrix24;
- PHP-разработка для коробочной версии;
- работа с Bitrix Framework и D7;
- доработка CRM и смарт-процессов;
- создание локальных модулей;
- обработка событий Bitrix;
- автоматизация создания коллабов;
- диагностика почтовой системы;
- настройка и проверка агентов и cron;
- подготовка данных для импорта в CRM;
- поиск и устранение ошибок в бизнес-процессах.

## Проекты

### Автоматическое создание коллаб

Бизнес-процесс создаёт отдельную коллабу для CRM-компании, сохраняет её идентификатор и адрес, получает рабочую электронную почту компании и отправляет приглашение внешнему пользователю.

### Синхронизация сделки и смарт-процесса

Локальный модуль отслеживает изменения элементов смарт-процесса, связанных со сделкой, и обновляет техническое поле сделки для запуска бизнес-процесса.

### Диагностика отправки почты

Набор проверок для поиска проблем с почтовыми событиями Bitrix24, PHP mail, msmtp и внешним SMTP-сервером.

### Проверка агентов и cron

Сценарии для анализа очереди агентов, времени последнего выполнения, просроченных задач и работы cron.

### Подготовка данных для импорта

Обработка и проверка данных компаний и реквизитов перед импортом в CRM Bitrix24.

## Подход к работе

Перед изменениями на рабочем портале я:

1. изучаю штатные возможности и API Bitrix;
2. проверяю классы и методы через PHP-консоль;
3. воспроизвожу задачу на тестовом портале;
4. добавляю журналирование;
5. проверяю возможные побочные эффекты;
6. только после проверки переношу решение в рабочую систему.
