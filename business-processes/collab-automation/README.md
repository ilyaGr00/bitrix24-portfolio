# Автоматизация создания коллабы

## Задача

Создавать отдельную коллабу для CRM-компании, сохранять её идентификатор и адрес, получать рабочую электронную почту компании и приглашать внешнего пользователя.

## Основные этапы

1. Получение CRM-компании.
2. Проверка, создавалась ли коллаба ранее.
3. Создание коллабы через API Bitrix24.
4. Сохранение идентификатора и адреса в CRM.
5. Поиск подходящего рабочего электронного адреса.
6. Отправка приглашения внешнему пользователю.
7. Запись результата и ошибок в журнал.

## Что демонстрирует проект

- работа с API коллаб;
- взаимодействие бизнес-процесса с CRM;
- защита от повторного создания;
- обработка ошибок;
- журналирование;
- работа с внешними пользователями.

Код будет добавляться отдельными проверенными действиями в папку `src`.
