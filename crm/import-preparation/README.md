# Подготовка данных к импорту

## Типовой порядок

1. Проверка обязательных полей.
2. Нормализация названий компаний.
3. Проверка ИНН и типа реквизитов.
4. Разделение адреса на части.
5. Поиск дубликатов.
6. Сверка количества строк.
7. Тестовый импорт.
8. Проверка результата.
9. Импорт основного набора данных.

Исходные клиентские таблицы в репозитории не публикуются.
