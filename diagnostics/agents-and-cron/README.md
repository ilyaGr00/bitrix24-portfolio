# Диагностика агентов и cron

## Что проверяется

- включён ли запуск агентов через cron;
- существует ли задание cron;
- запускается ли соответствующий PHP-скрипт;
- время последнего запуска;
- наличие просроченных агентов;
- ошибки PHP;
- права пользователя cron;
- доступ к документному корню портала.

В этот раздел будут добавлены безопасные диагностические команды и PHP-сценарии.
