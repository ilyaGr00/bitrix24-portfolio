# PHP-разработчик Bitrix24

Портфолио с примерами разработки, автоматизации, диагностики и сопровождения коробочной версии Bitrix24.

Работаю с CRM, бизнес-процессами, смарт-процессами, локальными модулями, серверной частью и внутренними механизмами платформы. В репозитории собраны обезличенные примеры кода и описания задач, основанные на реальной практике.

## Основные направления

- разработка локальных модулей для коробочной версии Bitrix24;
- создание PHP-действий для бизнес-процессов;
- доработка CRM, сделок, компаний, контактов и смарт-процессов;
- обработка событий Bitrix24;
- работа с D7 API, ORM и сервисами платформы;
- автоматизация создания коллабы и приглашения внешних пользователей;
- диагностика почтовых событий, SMTP, агентов и cron;
- установка, настройка и сопровождение коробочной версии;
- подготовка компаний, реквизитов и адресов к импорту;
- поиск и устранение ошибок без остановки рабочего портала.

## Подход к работе

Перед внедрением изменений я:

1. изучаю существующую конфигурацию;
2. проверяю штатные возможности Bitrix24;
3. выбираю подходящий API;
4. проверяю классы и методы в тестовой среде;
5. добавляю журналирование;
6. анализирую возможные побочные эффекты;
7. переношу решение на рабочий портал только после проверки.
