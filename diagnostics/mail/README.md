# Диагностика почты

Проверки выполняются по цепочке:

```text
Bitrix24 → почтовое событие → PHP mail() → msmtp → SMTP-сервер
```

## Что проверяется

- наличие событий в очереди;
- состояние таблицы почтовых событий;
- выполнение почтовых агентов;
- работа `mail()`;
- конфигурация `sendmail_path`;
- вызов msmtp;
- подключение к внешнему SMTP-серверу;
- журналы ошибок.

Изменения конфигурации выполняются только после определения проблемного уровня.
