# Обезличивание материалов

Перед публикацией необходимо заменить:

- названия компаний;
- ФИО;
- электронные адреса;
- телефоны;
- домены;
- IP-адреса;
- токены;
- пароли;
- идентификаторы пользователей;
- идентификаторы CRM-сущностей;
- идентификаторы пользовательских полей;
- внутренние пути и названия серверов.

Пример должен сохранять технический смысл задачи, но не раскрывать данные заказчика.
